# Sapera 診斷

此功能與相關來源目前限私有審查。硬體實作的來源授權尚未確認，不能由本文件推定已獲准散布。

CLI 或打包程式使用 `--sapera-diagnose`。診斷檢查 SDK、API、資源、CCF、連線、參數寫入、取像及清理；部分步驟會連線或寫硬體，須由有權操作的人執行。

相機已連線或監控中，不要建立第二個診斷連線。伺服器、resource、CCF 由操作者依自己的設備設定，示範版不提供現場值。

錯誤以 `[E-xxxx]` 與數字短碼呈現，對照 [設備錯誤碼](device-error-codes.md)。
詳細紀錄寫入本機 `outputs/logs/camera/`。紀錄可能含設備與影像資訊，不能隨示範版公開。

原廠 SDK 由設備使用者自行安裝，不包含在應用程式發布包中。
