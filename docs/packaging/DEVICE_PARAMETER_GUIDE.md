# TileScope AOI 設備設定說明

本版本只供私有示範及來源審查，不附任何產品或機台的校準設定。
硬體實作參考的既有取像程式已取得權利人同意；來源紀錄見隨包附的 `SOURCE_PROVENANCE.md`。

| 畫面 | 設定責任 |
| --- | --- |
| 相機設定 | 由有權操作的人選擇 server、resource、CCF，依自己的設備文件設定曝光、增益、行數與觸發 |
| 米輪（LSI-8181） | Card ID、自動遞增、倍頻、方向、CMP Out Width、CMP OUT 極性與 CMP0–CMP7 依自己的設備設定 |
| Sensor 中繼 | DI／DO、有效電位、脈寬與防抖由設備負責人確認；預設關閉 |
| 光源 | COM port、通訊參數與指令範本依自己的控制器文件設定 |

相機畫面的產品欄位名稱為「影像長度（線）」、「曝光時間」與「增益」；
米輪欄位包含「每幾格拍一行」。Sensor 欄位包含「每次觸發先把 Encoder 設為」與
「起拍偏移」。這些欄位都不提供產線範例數值，須由有權使用設備的人自行設定。

不要同時執行控制相同裝置的其他程式。
「Sensor DI」與「亮度指令範本」須依設備文件設定；以「儲存 Recipe」保存有權使用的產品設定。
示範 Recipe 不包含 camera 區段；載入示範 Recipe 不應寫入硬體。
`[E-xxxx]` 對照 `ERROR_CODES.md`。機台設定與 log 屬本機私有資料，不隨程式散布。
